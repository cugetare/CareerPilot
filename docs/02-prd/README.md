# 02 · PRD

Source of truth: [Confluence: CareerPilot – MVP PRD](https://glogoveanu.atlassian.net/wiki/spaces/PRD/pages/4292609). This page is a snapshot of the key decisions.

## Confirmed decisions

| Topic | Decision |
| --- | --- |
| Market | Germany only for the MVP; Spain is the second market |
| Languages | German and English (interface, ad analysis, documents) |
| Job sources | Public job lists of the Bundesagentur für Arbeit; Apply opens the original posting; no scraping. Partner feeds come with employer login |
| Free | Match score, confidence, "How this score is calculated", "Why it fits" (a few words, positives only), Apply, Save |
| Credits | 10 free credits per day; Prepare application, CV, cover letter and interview prep cost 1 credit each, regenerations included |
| Pay as you apply | "Coming soon" in the MVP: prepaid wallet (top-up from €10), 10-credit packs at €0.99, bought credits never expire and never affect ranking |
| Cost target | A complete application (4 credits) costs under €0.01 in AI and infrastructure at scale |
| Interview prep | Offered from the application history after the user confirms an application; first item to cut if planning runs tight |
| Sign-in | Standard SSO: Google, Microsoft, Apple, GitHub, LinkedIn |
| Business model | MVP investor-funded; after launch employers pay for job ads and talent search (employer login) |
| Team | 2 engineers, 1 ML engineer, 1 PM; 2-week sprints |
| Launch | 14 June 2027, fixed Q2 deadline |

## Timeline

S1–S6 validate the problem and design the solution (Oct 2026 – Jan 2027). Build runs as Jira Sprint 1–6 (S7–S12, 11 Jan – 2 Apr 2027), hardening S13–S14, closed beta in May, public launch 14 June 2027.
