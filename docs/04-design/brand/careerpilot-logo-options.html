CareerPilot: three logo directions

Each direction uses the crosshair "o" in "Pilot" and is checked against the four tests: it works at 16 px, works in one colour, can be described in one sentence and is not a trend. Proposed palette: one primary, one secondary, one accent.

A · Reticle wordmark

Wordmark (cheapest to get right) · "CareerPilot, where the o is a crosshair."

Why it works

  • Pure wordmark: the name gets learned, not a symbol.
  • The orange centre dot is the only accent and stands for "your target role".
  • The icon is just the "o", so app icon and favicon come free.

Watch out

  • Outer ticks read as a rifle scope if they get too long; keep them short.
  • The ticks widen the letter, so check the kerning around "l" and "t".

B · Two-weight wordmark

Wordmark · "career light, pilot bold, the o is an orange notched ring."

Why it works

  • Lowercase and two weights feel approachable for graduates like Lena.
  • "pilot" in bold puts the stress on guidance, not on the job hunt.
  • The crosshair stays inside the letter outline, so it never looks like a weapon.

Watch out

  • The orange ring on white is about 3.5:1 contrast: fine for a graphic, never for text.
  • The light weight thins out under ~20 px; use the bold-only version there.

C · Combination mark

Symbol + name, splittable for app icons · "A navy tile with a crosshair, next to CareerPilot."

Why it works

  • The tile is a ready-made app and social icon; the name stays plain and readable.
  • The ticks point inward, so it reads as "focus", not "scope".
  • Easiest to apply in Figma: the icon and the wordmark are separate components.

Watch out

  • The name itself has no crosshair, so the "o" idea lives only in the icon.
  • At 16 px the ticks must be dropped (shown), which adds a variant to maintain.

Proposed palette (60 / 30 / 10)

Pilot Navy · #0F2A4A
Primary, 60%: text, surfaces, brand. 14.5:1 on white.
Sky Mist · #E8EEF6
Secondary, 30%: cards, hover, calm areas.
Target Flare · #F2542D
Accent, 10%: the crosshair dot and the main button only. 3.5:1 on white, so large or bold text only.

Type: one family (Inter or a system stack), weights 300 / 800 only. Before final use, run a trademark search on any crosshair-in-letter mark in the job and HR software classes, as it is a common motif.
